# Generator Tracker - Опис для Google Play Store

## Короткий опис (80 символів максимум)
Облік годин роботи генераторів, заправок та аналіз ефективності.

## Повний опис

**Generator Tracker** - потужний мобільний застосунок для відстеження годин роботи генераторів, споживання палива та обслуговування. Ідеальний для бізнесу, підрядників та власників, яким потрібен надійний моніторинг генераторів.

### 🎯 Ключові можливості

**Швидкий старт/стоп сесій**
- Запуск/зупинка сесії одним дотиком
- Відстеження часу в реальному режимі
- Автоматичний підрахунок годин
- Перегляд активних сесій

**Комплексний облік**
- Журнал робочих годин з точними часовими мітками
- Запис заправок з датою та кількістю
- Додавання нотаток до сесій та заправок
- Відстеження декількох генераторів

**Облік технічного обслуговування**
- Повторювані сервісні завдання для кожного генератора (заміна масла, фільтрів, сезонні перевірки)
- Інтервали за мотогодинами, за днями або за обома критеріями
- Наочний статус: OK, Скоро ТО або Час ТО
- «Виконано» — скидання завдання в один дотик
- Позначки про близьке та прострочене ТО на головному екрані

**Розумна аналітика**
- Перегляд загальних годин роботи кожного генератора
- Моніторинг споживання палива
- Розрахунок середньої витрати на годину
- Фільтрація аналітики по конкретному генератору або перегляд усіх разом
- Аналіз по всіх генераторах

**Хмарна синхронізація та безпека**
- Синхронізація через Firebase
- Вхід через Email/Пароль та Google
- Архітектура offline-first - працює без інтернету
- Автоматична синхронізація при появі з'єднання

**Сучасний нативний дизайн**
- Виглядає як рідний застосунок: Material 3 на Android, нативний дизайн iOS на iPhone та iPad
- Світла й темна теми — за налаштуванням системи
- Енергетична помаранчево-синя кольорова схема
- Зручне розташування на планшетах і складних смартфонах

**Професійні функції**
- Редагування будь-якої сесії чи заправки
- Видалення генераторів з усіма даними
- Оновлення даних жестом
- Структура даних готова до експорту

### 📊 Ідеально підходить для

- **Будівельних компаній**: Облік роботи обладнання
- **Event-сервісів**: Моніторинг генераторів на заходах
- **Власників будинків**: Обслуговування резервних генераторів
- **Керуючих компаній**: Управління декількома об'єктами
- **Підрядників**: Точний облік робочих годин для рахунків
- **Сервісних команд**: Планування інтервалів обслуговування

### 🔒 Конфіденційність та дані

- Ваші дані зберігаються локально на пристрої
- Опціональна хмарна синхронізація для резервного копіювання
- Без реклами, без відстеження
- Повний контроль над вашою інформацією

### 💡 Чому Generator Tracker?

**Економія коштів**: Оптимізація витрат палива та графіків обслуговування
**Організованість**: Всі дані генераторів в одному місці
**Робота офлайн**: Відстеження годин навіть без інтернету
**Професійні звіти**: Чисті дані для рахунків та аудиту

### 🆕 Що нового у версії 2.5.0

- **Нативний дизайн**: нативна навігація Material 3 на Android; нативні навігація, форми й налаштування iOS на iPhone та iPad.
- **Темна тема**: застосунок тепер іде за світлою/темною темою пристрою.
- **Планшети**: зручне центроване розташування на планшетах і складних смартфонах; графіки вміщуються в екран.
- **Правильні дати після півночі**: записи, створені невдовзі після опівночі, тепер отримують правильну дату.
