# Release Notes 2.0.3

**Date:** 2026-02-06
**Version:** 2.0.3

## Overview
This update introduces a modernized app icon and improves the user interface on small screens.

## 🆕 What's New
- **Modern App Icon**: A completely redesigned, energy-themed app icon with high contrast and modern aesthetics.

## 🐛 Fixed
- **UI Layout**: Fixed the Floating Action Button (FAB) position on the Home screen to prevent it from hiding behind the bottom navigation bar on small screens.
