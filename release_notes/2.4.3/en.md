# Release Notes 2.4.3

**Date:** 2026-09-30
**Version:** 2.4.3

## Overview
A maintenance update: the app now runs on the latest React Native / Expo platform, which keeps it compatible with current Android and iOS versions. No new features.

## 🐛 Fixed
- **"+" button position**: the button for adding a generator no longer overlaps the bottom navigation bar on phones with gesture navigation and on tablets.
- **Missing icons**: the empty "Sessions" and "Refills" tabs now show their icons instead of a question mark.

## 🔧 Technical
- Upgraded to Expo SDK 57 (React Native 0.86).
- Prepared the app for iOS 27.
