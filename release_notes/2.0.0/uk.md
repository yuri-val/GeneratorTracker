# Версія 2.0.0 — Повний редизайн інтерфейсу
**Дата випуску:** 6 лютого 2026

## Огляд
Generator Tracker 2.0 — це повне візуальне оновлення, побудоване на Material Design 3 з React Native Paper. Кожен екран перероблений з сучасними компонентами, плавними анімаціями, тактильним відгуком та інтерактивними графіками.

## Що нового

- **Material Design 3 UI** — Всі екрани перебудовані з компонентами React Native Paper для відполірованого, послідовного дизайну
- **Інтерактивні графіки** — Нова панель аналітики зі стовпчиковими діаграмами (години роботи, споживання палива, порівняння генераторів) та круговими діаграмами (розподіл палива)
- **Пружинні анімації** — Плавні анімації появи карток, кнопки FAB, панелей статистики та елементів графіків
- **Тактильний відгук** — Haptic feedback при старті/зупинці сесій, збереженні форм, видаленні елементів та натисканні FAB
- **Скляна панель навігації** — Ефект матового скла на нижній панелі навігації з прозорістю
- **Градієнтні активні сесії** — Запущені сесії тепер відображаються красивими зеленими градієнтними картками
- **Покращена аналітика** — Перемикання між Оглядом (сітка статистики) та Графіками через сегментовані кнопки
- **Перероблені форми** — Всі поля вводу використовують Material Design з іконками та підказками валідації
- **Діалоги підтвердження видалення** — Material діалоги замість системних сповіщень

## Технічні зміни
- Міграція на React Native Paper v5 (Material Design 3)
- Додано React Native Reanimated v4 для анімацій
- Додано Expo Haptics, Expo Blur, Expo Linear Gradient
- Додано React Native Gifted Charts для візуалізації даних
- Нова централізована система тем з типобезпечним хуком
- Без змін у моделях даних чи синхронізації — всі ваші дані збережені
