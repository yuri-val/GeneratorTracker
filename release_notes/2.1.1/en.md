# Release Notes 2.1.1

**Date:** 2026-02-06
**Version:** 2.1.1

## Overview
This update modernizes the app's visual identity with a completely redesigned icon and streamlines the build process with improved version management.

## 🎨 What's New

**Modern App Icon**
- Completely redesigned app icon with a contemporary, energy-themed aesthetic
- High-contrast design for better visibility across all device backgrounds
- Updated favicon and splash screen icons for a cohesive visual experience
- Modern look that reflects the app's focus on power and energy tracking

## ⚡️ Technical Improvements

**Enhanced Build Process**
- Enabled EAS Build's automatic version code management for Android
- Simplified release workflow by removing custom versioning scripts
- More reliable and consistent build numbering across releases
- Streamlined development and deployment process
