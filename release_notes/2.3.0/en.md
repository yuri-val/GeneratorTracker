# Version 2.3.0 — Generator Filter on Analytics

**Release Date:** February 18, 2026

## Overview

This release adds the ability to filter analytics data by individual generator, giving you more focused insights into each generator's performance.

## What's New

- **Generator Filter Chip Bar** — A horizontal scrollable chip bar on the Analytics screen lets you quickly switch between "All Generators" and any specific generator.
- **Filtered Stats** — Overview statistics (total hours, fuel used, average hours) now update to reflect the selected generator.
- **Smart Chart Visibility** — "Generator Comparison" and "Fuel Distribution" charts automatically hide when viewing a single generator, keeping the interface clean and relevant.
- **Filtered Charts** — "Operating Hours" and "Fuel Consumption" time charts show data only for the selected generator.
